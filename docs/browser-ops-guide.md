# 运维浏览器使用指南

运维界面 → 浏览器页签，是 fairpeer 的浏览器运维工作台。本指南面向团队成员，覆盖日常使用路径。

## 一、界面地图

- **右侧栏（驾驶舱）**：三个子页签——「交互」（手动驱动）、「录制」（录操作生成技能）、「技能」（技能库）
- **会话栏**：打开/关闭浏览器、保持会话开关（长间隔任务防掉线）
- **观察窗（中间大视图）**：点侧栏启动条打开——页卡条 + 大画面；画面源可切「控制台 / agent 会话」，看 fairpeer 自动执行时切到 agent 源围观
- **动作记录**：面板每个操作记一步，「记录为技能」一键转技能草稿

## 二、手动操作（交互页签）

1. 打开浏览器 → 地址栏输网址（**不带 http 也行，自动补 https**）→ 前往
   - **浏览器是持久的**（固定 profile + 固定端口）：关掉 fairpeer 浏览器不会死，下次打开 fairpeer 点「打开浏览器」直接**接管**上次的浏览器——页卡、登录态原样都在（会话栏显示「接管」）。
   - **对话里的浏览器技能也用这同一个浏览器**：技能/agent 会话自动接管当前受控浏览器（没有才拉起），人工登录的页卡直接复用；技能在**自己的新页卡**上操作，不会把你正看的页面导航走浏览器被手动关掉时，下次会用同一个 profile 拉起并恢复登录态与上次页卡（`--restore-last-session`）。想彻底清空登录态：删除 `~/.fairpeer/console-browser` 目录
   - **关闭层级**：观察窗右上角 ✕（或 Esc）只关观察窗视图；面板「关闭浏览器」**真正关闭整个受控浏览器**（全部页卡+进程，优雅关闭、登录态落盘，下次打开重新拉起并恢复）
2. 点「刷新元素」读页面可交互元素：**过滤框**按角色/名称缩小范围（默认最多显示 50 行），**点选后目标栏自动填稳定锚链**（CSS;;text=名称——编号 eN 是当次快照的临时值，只在当场有效，永不写入技能）
   - 列表覆盖三类：无障碍树可交互角色（按钮/链接/输入框…）、**带文字的指针 div/span**（组件库做的页签/工具块，两者同权判定）、img/svg 伪按钮；图标且无文字的可点元素不进列表——从 F12 复制 CSS 粘到目标栏即可操作
   - 长页面无需滚动——元素列表本来就拿**整页**（含视口外）的无障碍树
   - **瀑布流/懒加载页**点「⇊ 深度扫描」：自动逐屏下滚收集懒加载出来的元素，带稳定锚点（`#id` / `name=` / `text=文字`），滚完回到原位。无限流拿不到"全部"（内容滚不完），扫描按预算停止并在汇总行说明原因（无新增 / 到底 / 达滚动上限 / 达数量上限）
3. 目标 + 文本 → 输入 / 点击 / **悬停**（悬浮菜单：先悬停让菜单展开，再拿元素点菜单项）；提取框可选格式：**纯文本 / Markdown / 表格**——Markdown 保留标题、加粗、代码、列表结构（AI 回答块用这个），表格保留 `<table>` 行列——提取会记入动作记录成为技能步骤（技能里值列写 markdown/table）；提取的**内容一般需要二次加工**（整理/改写）再使用，编排技能时把 extract 放最后一步，输出落在执行报告里便于取用
4. 页面开了新页卡（target=_blank）：fairpeer **自动跟随**到新页卡；观察窗里可看页卡条手动切换，切换后元素列表自动刷新
5. **页面跳转元素列表自动刷新**：地址栏前往、点了会跳页的链接、后退/前进、甚至你直接在被控浏览器里手动浏览——面板每 3 秒对比当前网址，发现页面变了就自动重抓元素（地址栏前往会立即刷新，不等轮询）
6. 悬停/点选元素行：页面里对应位置会**橙色框选**（再点一次取消）

## 三、把操作沉淀成技能（三条路）

| 路 | 适合 | 产出 |
|---|---|---|
| **录制页签** | 你在浏览器里手动走一遍（含登录、验证码） | 轨迹 → AI 归纳成步骤表草稿 |
| **动作记录 → 记录为技能** | 你在面板上逐步发指令 | 操作序列直接转步骤表草稿；**每条记录可单独删除**（点错一步不用整份重来），删完再生成 |
| **技能页签 → 新建技能** | 从模板起步 | 8 个模板：空白 / 登录保活 / 表单填报 / 流式问答 / 数据导出 / 页面巡检 / 安全日志值守 / 值守循环 |

技能保存后为**草稿**（未唤醒）：面板可编辑/**试运行**/导出，但对话里不可调用（索引不收录、run_skill 会提示先唤醒）；技能页点「**唤醒**」转正后 `/技能名` 才可用。生成 → 试运行打磨 → 唤醒，是推荐节奏。

## 四、步骤表怎么写才稳（多锚定位）

目标列支持**回退链**，`;;` 分隔、按序尝试：

```
#login-btn;;text=登录
```

- CSS 锚（id / data-testid / name 最稳）失败后，自动按**可见文字**在 DOM 里定位
- **定位自带等待**：click/type 等步骤的目标如果还没渲染出来，内核最多**等 8 秒**出现再执行一次（只等定位、绝不重复动作）；等待超 1 次才成功会在步骤报告里提示
- **重 JS 站点标准搭配**（元素可见 ≠ 事件已绑，JS bundle 可能还没执行完）：
  1. `navigate` 之后 `wait networkidle`（网络 500ms 无新请求 ≈ JS 装载执行完）
  2. 按钮没就绪多半带 `disabled`——目标写 `button[type=submit]:not([disabled])`，等应用自己宣告就绪
  3. 点击后跟一行效果等待（`wait visible:结果` / `wait url:/next`）确认真的生效——这是唯一能发现"点了没反应"的方式
- 悬停展开的菜单：菜单项点击前插一行 `hover` 步骤（真实鼠标移动，CSS :hover 才生效）
- 切换页卡：`switch_tab` 步骤，**目标列优先填页卡标题**（按名字精确→包含匹配，比序号稳——序号随页卡开关漂移）；也可填 1 起始序号。观察窗或面板切页卡时自动按标题记录
- 等流式输出完成：`wait`，条件 `stable:输出容器选择器`（首 token 之前——目标未出现/空块/「正在…」类占位文案/aria-busy——内核绝不判稳，AI 后端 30-60 秒思考期不会提前放行；内容流式后自适应判稳：停止变化后静默 2-8 秒，回答越长静默要求越长——中途检索停顿不会误判完成）
- **超时值直接写秒数且 ≤600**（如 `60s` / `300s`，上限 `600s`）：大于 600 且带 `s` 的写法会被解析器按毫秒读（`50000s` 实为 50 秒），保存时直接拒绝并提示改写
- 人必须做的（验证码/登录/扫码）：`human` 步骤 + 完成检测条件（如 `url:/home`）
- 运行时才知道的值：`ask` 步骤（面板试运行弹输入框；对话调用时参数传入 `工单号=A123`）

## 五、确定性执行（长流程要稳定必开）

编辑器顶部勾「**确定性执行**」（frontmatter `executor: browser-flow`）：

- 对话 `/技能名` 时**内核逐步原样执行步骤表**，不走 AI 临场发挥——站点改版前技能行为不变
- human 步骤靠检测条件放行（浏览器窗口可见，你操作，条件满足自动继续）
- 面板试运行不受影响（照样交互式暂停/输入）

## 六、定时与值守

- 对话里说「每 30 分钟运行一次 browser-siem-watch」→ 调度器建任务（支持 every / cron / daily，跨重启持久化）
- 「安全日志值守」模板专为无人值守设计：掉线发邮件通知重登而不是等人
- 「值守循环」是人工在场的对话式协议：开局登录后逐轮接指令

## 七、会话保活

会话栏「保持会话」：每 tick 防本地空闲回收 + 页内心跳滑动站点登录有效期；状态行显示上次刷新时间。对话侧等价工具：`browser_keepalive`。

- **`ping`（默认）作用所有页卡**：每个打开的页卡各自发一次同源心跳——页卡 1 的安全平台和页卡 2 的监控系统登录态**都**被保住（Cookie 按站点隔离，单页卡心跳救不了另一个站）。个别页卡失败只记状态行错误，其余页卡照常保活
- `navigate` 定时整页刷新**仅当前页卡**（顽固站点用）：自动刷新所有页卡会冲掉其他页卡里未保存的表单，不做
- `local` 只防本地空闲回收，不碰站点

## 八、技能分享

技能就是 `~/.fairpeer/skills/<名字>/SKILL.md` 单文件：技能行「导出」下载 .md，同事「导入」检查后保存即用。

## FAQ

- **点元素报「编号已失效」**：页面变过了，点「刷新元素」重选（编号是瞬时坐标）
- **网址报「无效」**：检查空格/特殊字符；裸域名会自动补 https
- **重启后要重新登录**：正常——浏览器随应用退出，cookie 多数还在，短会话站点需重登一次
- **对话里跑技能看不到画面**：打开观察窗，画面源切到对应 agent 会话
