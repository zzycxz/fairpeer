| E7 | 模型能力档案（model_cards：实勘矩阵/量化×硬件族/MoE 双参数） | 与 E4 配对 | E4 |
| E5 | GPU 值班排查手册（八簇失败模式→docs 手册） | ~半天 | 无 |

## 六、横切纪律（贯穿所有里程碑）

1. **真机变量**：M1/M2 全部无真机依赖（先行的理由）；M-1 代码先行 fixture 验收，真机终验挂 G 批；每月问一次真机时间表。
2. **并行批次协调**（U5）：每次并行落地后跑标记清单核对（已两次覆盖事故）；共享文件提交前 diff 复核。
3. **范围纪律**：新想法先进台账（GAPS 准入制）再排批；H 批域外清单是宪法。
4. **验收门禁**：每里程碑全量门禁（build/vet/netdev 全量/desktop/tsc/vite/定向 race）+ 里程碑专属验收项。
